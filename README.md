# DietUp Course Registration

افزونه اختصاصی ثبت‌نام دوره «آمپول‌های لاغری | دایت‌آپ» برای وردپرس.

## نصب
1. پوشه افزونه را در مسیر `wp-content/plugins/dietup-course-registration` قرار دهید یا ZIP افزونه را از بخش افزونه‌ها بارگذاری کنید.
2. افزونه **DietUp Course Registration** را فعال کنید.
3. در یک برگه المنتور، ابزارک Shortcode را قرار دهید و شورت‌کد زیر را وارد کنید:

`[dietup_registration]`

## امکانات پیاده‌سازی‌شده
- فرم فارسی ثبت‌نام با اطلاعات فردی و حرفه‌ای و سه پکیج
- نمایش شرطی فیلد نام انگلیسی برای گواهی و محل فعالیت «سایر»
- اعتبارسنجی سمت سرور، پاک‌سازی ورودی‌ها و nonce وردپرس
- ذخیره اطلاعات در جدول اختصاصی؛ بدون ساخت حساب کاربری وردپرس
- پنل مدیریت ثبت‌نام‌ها با جست‌وجو و فیلتر پکیج/وضعیت پرداخت
- آمار ثبت‌نام، پرداخت‌های موفق و مجموع فروش تأییدشده
- خروجی CSV با UTF-8 BOM و خروجی واقعی XLSX برای Excel
- اتصال سمت سرور زیبال برای ایجاد تراکنش، بازگشت امن و Verify سروری
- کنترل مبلغ تأییدشده با مبلغ سفارش و جلوگیری از تأیید صرفاً بر اساس پارامتر callback
- درخواست ساخت لایسنس SpotPlayer با API رسمی پس از پرداخت تأییدشده
- صفحه خصوصی نمایش کلید لایسنس با توکن تصادفی و ذخیره hash توکن
- پنل بارگذاری/جایگزینی/حذف ویدئوی MP4 و جزوه PDF پکیج کامل
- نگهداری فایل‌های پکیج کامل در مسیر خصوصی خارج از web root و تحویل از مسیر کنترل‌شده فقط به خریداران تأییدشده پکیج کامل
- ستون‌های وضعیت پرداخت، شناسه تراکنش و وضعیت لایسنس

## پیش‌نیازهای تکمیل اتصال‌ها
- **درگاه زیبال:** آداپتور درخواست و Verify سمت سرور اضافه شده است. شناسه پذیرنده باید در تنظیمات وارد شود. مبلغ‌های فرم تومان هستند و برای API زیبال به ریال تبدیل می‌شوند.
- **SpotPlayer:** آداپتور رسمی ساخت لایسنس اضافه شده است؛ API Key و شناسه دوره باید در تنظیمات وارد و روی حساب واقعی آزمایش شوند.
- **پکیج کامل:** پنل بارگذاری امن و تحویل کنترل‌شده فایل‌های MP4/PDF پیاده‌سازی شده است. مدیر سایت فایل‌ها را از منوی دایت‌آپ ← فایل‌های پکیج کامل بارگذاری می‌کند. محدودیت اندازه فایل تابع تنظیمات PHP/هاست است.
- **گزارش Excel:** خروجی XLSX واقعی از پنل ثبت‌نام‌ها اضافه شده و به PHP ZipArchive نیاز دارد.
- تلاش مجدد لایسنس فقط برای خطای قطعی تنظیمات که پیش از فراخوانی SpotPlayer رخ داده باشد، از پنل مدیریت فعال است. خطاهای مبهم شبکه/پاسخ با وضعیت «نیازمند بررسی دستی» ثبت می‌شوند و به‌صورت خودکار تکرار نمی‌شوند تا لایسنس تکراری ساخته نشود.
- تست عملی end-to-end با Merchant ID و حساب واقعی SpotPlayer هنوز انجام نشده است.

## نیازمندی‌ها
- WordPress 6.4+

## امنیت
- هیچ کلید API یا اطلاعات محرمانه‌ای را در Git قرار ندهید.
- مخزن کد اختصاصی را Private نگه دارید.
- وضعیت پرداخت فقط پس از Verify سمت سرور درگاه باید موفق شود.


## تنظیمات اتصال‌ها
پس از فعال‌سازی افزونه، از منوی **دایت‌آپ ← تنظیمات اتصال‌ها** می‌توانید اطلاعات درگاه پرداخت و SpotPlayer را وارد کنید:
- زیبال: شناسه پذیرنده (Merchant ID)
- SpotPlayer: کلید API و شناسه دوره (Course ID)

کلید API اسپات‌پلیر هنگام نمایش صفحه دوباره آشکار نمی‌شود؛ برای حفظ کلید قبلی، فیلد رمز را خالی بگذارید. برای پاک‌کردن کلید ذخیره‌شده، گزینه حذف آن را علامت بزنید. این اطلاعات در گزینه اختصاصی وردپرس با غیرفعال‌بودن autoload ذخیره می‌شوند.

**مهم:** آداپتورهای زیبال و SpotPlayer طبق مستندات رسمی اضافه شده‌اند، اما تا زمان واردکردن اطلاعات واقعی و اجرای پرداخت آزمایشی، استفاده عملیاتی را تأیید نکنید. درخواست صدور لایسنس SpotPlayer از سمت سرور انجام می‌شود. به‌دلیل نبود تضمین idempotency در API ساخت لایسنس SpotPlayer، وضعیت مبهم ناشی از timeout نباید کورکورانه دوباره ارسال شود.


## ثبت‌نام متصل به حساب کاربری و نمایش دسترسی دوره

- افزونه از سیستم ورود فعلی قالب استفاده می‌کند و حساب کاربری جدید نمی‌سازد. کاربر باید پیش از ارسال فرم وارد حساب وردپرس باشد.
- شورت‌کد فرم همچنان `[dietup_registration]` است.
- پس از ثبت فرم، نام، نام خانوادگی و ایمیل در پروفایل همان کاربر به‌روزرسانی می‌شوند؛ ایمیلی که متعلق به حساب دیگری باشد پذیرفته نمی‌شود.
- مدرک تخصصی (JPG، PNG یا PDF) به کتابخانه رسانه وردپرس افزوده و شناسه آن به ثبت‌نام وصل می‌شود. مدیر از منوی «دایت‌آپ ← مدارک ثبت‌نام» می‌تواند تصویر بندانگشتی را باز کند.
- پس از تأیید پرداخت، کاربر به همان برگه فرم برمی‌گردد و لینک کانال تلگرام و منابع مجاز پکیجش را می‌بیند. افزونه فقط لینک و متن کانال را نمایش می‌دهد و مدیریت عضویت تلگرام انجام نمی‌دهد.
- لینک و متن راهنمای کانال در «دایت‌آپ ← تنظیمات نمایش دوره» تنظیم می‌شوند.
- برای نمایش سوابق در صفحه حساب کاربری قالب، شورت‌کد `[dietup_my_courses]` را در محتوای صفحه مربوط به حساب کاربری قرار دهید. عنوان این بخش «دوره‌های ثبت‌نام‌شده از طریق فرم» است.
- پکیج آنلاین فقط لینک کانال را نشان می‌دهد؛ پکیج آنلاین + گواهی جزوه را نیز دارد؛ پکیج کامل علاوه بر جزوه، کد اختصاصی SpotPlayer و فایل آفلاین را نشان می‌دهد.
- مهاجرت فقط ستون‌های افزوده‌شده را به جدول فعلی اضافه می‌کند؛ رکوردهای قبلی حذف یا بازنویسی نمی‌شوند. ثبت‌نام‌های قدیمی به‌صورت خودکار به کاربران وصل نمی‌شوند.
