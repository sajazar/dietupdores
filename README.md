# DietUp Course Registration

افزونه اختصاصی ثبت‌نام دوره آمپول‌های لاغری دایت‌آپ برای وردپرس.

## وضعیت توسعه

این مخزن در مرحله ساخت اسکلت امن افزونه است. اتصال درگاه پرداخت و SpotPlayer تا دریافت مشخصات واقعی و آزمون sandbox فعال نخواهد شد.

## شورت‌کد

`[dietup_registration]`

## نیازمندی‌ها
- WordPress 6.4+
- PHP 8.1+

## امنیت
کلیدهای API و اطلاعات درگاه نباید در Git ذخیره شوند. تنظیمات محرمانه فقط در پنل وردپرس نگهداری شوند.
